# PyTorch's own package index, for the CPU-only build. Declared as an
# `--extra-index-url` (not `--index-url`) so pip still falls through to
# PyPI for every other package here — only `torch` itself has a build on
# this index. Without this, `pip install torch` resolves the default PyPI
# wheel, which pulls the CUDA runtime (~2GB of nvidia-*-cu12 packages)
# nothing in this codebase uses: `tft_model.py` hardcodes `accelerator="cpu"`
# unconditionally. Kept in requirements.txt itself (not a build-time flag)
# so `pip install -r requirements.txt` resolves identically everywhere —
# a developer's laptop, CI, and the Docker image all get the same graph.
--extra-index-url https://download.pytorch.org/whl/cpu

# Core engine — required, imported unconditionally at module load time.
